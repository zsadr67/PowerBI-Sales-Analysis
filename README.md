# Adventure Works Sales Data Analysis

An interactive Power BI dashboard project designed to analyze sales performance, customer behavior, and product trends for Adventure Works.

## 📊 About the Project
This dashboard transforms raw transactional data into actionable business insights. It provides a comprehensive view of sales dynamics, helping stakeholders make data-driven decisions through intuitive visualizations and KPIs.

## 🛠 Tools & Technologies
* **Power BI Desktop:** For report design and visualization.
* **DAX (Data Analysis Expressions):** Used for complex calculations, Time Intelligence functions, and dynamic metrics.
* **Power Query:** Used for data cleaning, transformation, and establishing a robust data model.

## 🚀 Key Features
* **Data Modeling:** Implemented a **Star Schema** architecture to ensure optimal performance and query efficiency.
* **Interactive UI:** A 3-page dashboard featuring seamless page navigation and "Reset Filter" functionality.
* **Advanced Analytics:**
    * **Dynamic Ranking:** Implemented Top/Bottom N product analysis using `RANKX`.
    * **Customer Segmentation:** Visualized New vs. Returning customers to track loyalty.
    * **Data Integrity:** Utilized Tooltips to transparently manage and display limitations in the 2019 data.

## 💡 Key Business Insights
* **Profitability vs. Volume:** Identified that while Accessories drive transaction frequency, Bikes (specifically Mountain-200) account for over 80% of net profit.
* **Customer Retention:** Successfully tracked recurring purchasing patterns, revealing growth in customer loyalty starting mid-2018.
* **Portfolio Optimization:** Refined product strategy by clearly distinguishing between high-performing active products and non-performing items.
